# 探针 / 惰性区检测 + 重放比例重规划：CPU 小实验

问题：用核漂移检测"是否脱离惰性区"，脱离时重新线性化并更新重放比例 r，区内沿用——
能否比只在 θ_A 线性化一次（P_lin2）更接近最优的 r？

## 设定
- 单隐层 tanh MLP（NTK 参数化，无偏置），h = 256 或 64；输出按 Chizat 等（2019）缩放：
  f = α·(g(θ) − g(θ₀))，损失乘 1/α²。α 不改变线性化动力学，只控制真实核漂移多少：
  α = 1 惰性，α = 0.05 / 0.02 富特征。
- 数据：sklearn digits。任务 A = 原图，任务 B = 旋转 90° 或固定像素置换；每任务 150 张。
- 损失：MSE（中心化 one-hot），任务内平均；混合目标 (1 − r)·L_B + r·L_A；全批量 GD（无 SGD 噪声）。
- T：两个任务同时进入容差带的第一步：L_B ≤ 0.1·L_B(θ_A)，L_A ≤ L_A(θ_A) + 0.03·L_B(θ_A)。
- 基准：r 网格 {0.1, 0.2, 0.3, 0.35, …, 0.7, 0.8, 0.9} 上逐个真实训练，取最优固定 r。
  后悔比 = 方法的 T / 最优固定 r 的 T；小于 1 表示比任何固定 r 都快。

## 方法
| 名称 | 做法 |
| --- | --- |
| P_lin2 | 两任务都在 θ_A 线性化（函数空间 NTK），预测每个 r 的 T，选一次 |
| probe_swap | 在 P_lin2 选的 r 上真实训练"预测步数的 15%"作为探针，取探针终点的核，从头重新预测 |
| probe_piece | 同上，但探针长度内用旧核、之后用新核 |
| probe_cont | 保留探针的训练进度，从探针终点用新核重规划一次 |
| trig_ε | 在线：每约 1/10 预测训练长度检查一次；60 个固定样本上的 NTK 相对上次线性化点的变化 > ε 时，重新线性化并从当前状态重规划 r；否则沿用 r |
| periodic | 每次检查都重新线性化并重规划 |
| replan_only | 每次检查都重规划，但一直用 θ_A 的核 |
| trig_replan_ε | 每次检查都重规划；只有漂移 > ε 时才重新线性化（GPU 代码里叫 mpc_ε） |
| pe_replan_ε | 同上，但触发信号是线性模型对上一窗口的预测误差 δ = ‖E_real − E_pred‖ / ‖E_real − E_prev‖，不需要雅可比（GPU 代码里叫 mpcpe_ε） |

## 文件
- core.py：数据、网络、解析 NTK（有限差分检验误差约 1e-11）、真实训练、线性化模拟、规划
- scan.py / scan2.py：场景扫描（P_lin2 选的 r 与真实最优 r 对比，种子 0）
- exp.py / batch.py：主对比（27 个配置）→ results.jsonl
- exp_extra.py：重规划变体 → results_extra.jsonl
- exp_prederr.py：预测误差触发 → results_prederr.jsonl（ε = 0.05 / 0.1 / 0.2；全部 27 个配置平均后悔比 0.981 / 0.982 / 0.982，最差 1.037，平均重线性化 4.8 / 3.5 / 2.7 次）
- aggregate.py：按惰性区 / 富特征区汇总；summarize.py：逐配置明细
- fig_curves.py → fig_T_curves.png
- run_all.sh：全部重跑（2 核 CPU 约 2 小时）
